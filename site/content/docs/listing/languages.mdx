---
title: Languages
description: Adding a language to the listing and the screenshots, and starting it from the default one.
---

The app's languages are in **Settings**, with the default one. Each language has its own store
text, its own screenshot copy and, unless a screen says otherwise, its own captures.

A language with no store text yet shows **No text in this language yet**. **Start from** the
default language fills every field with the default language's text, to translate. The
screenshot copy works the same way in Design: **Create from** makes the language's content file
with every field filled in.

Right-to-left languages mirror the screenshot layouts. The [Languages view](/docs/design/views)
shows one screen in every language at once.
